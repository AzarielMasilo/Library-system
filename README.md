# Community Library Management System

A React web application for managing library books, tracking availability, and handling user accounts with local storage persistence.

## Features
- Add, edit, and delete books
- Track book quantity and available copies
- Borrow and return books
- Manage user accounts
- React Router navigation
- Local storage persistence
- Form validation

## Technologies
- React
- Vite
- React Router DOM

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```
